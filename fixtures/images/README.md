# Fixture images

Synthetic photos (brick-like shapes on plain backgrounds) generated by the inference test
suite (`inference/tests/fixtures/`, see its `manifest.json` for piece counts and colors).
They are used by the E2E tests and for demos with `PART_CLASSIFIER=stub`.

There are no real photos yet. Add real photos of spread pieces here as `real_*.jpg`, together
with their expected counts, for the manual tests listed in `tests/report.md`.
